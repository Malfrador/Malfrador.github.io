Event Modal Component Demo

Shows the bookmark confirmation popup in action

Modal Examples

How to use: Click any button below to trigger the modal. The modal includes:

  • Desaturated image (saturate: 0%, opacity: 40%)
  • Close button (X) in top right
  • Purple button with sparkle animation and color inversion on hover
  • Responsive design that works on mobile and desktop

Usage Example:

// Simple usage
EventModal.show({
    title: "Event hinzugefügt",
    eventName: "Pottery Workshop",
    buttonText: "Zum Event",
    buttonLink: "/events/pottery",
    imageUrl: "path/to/image.jpg"
});

// Or create instance for more control
const modal = new EventModal({
    title: "Event hinzugefügt",
    eventName: "Your Event Name",
    buttonText: "Zum Event",
    buttonLink: "#",
    imageUrl: "image.jpg"
});
modal.create();
// Later: modal.close();

Integration Guide

1. Include Files

Add these files to your HTML head:

<link rel="stylesheet" href="css/modal.css">
<script src="js/modal.js"></script>

2. Trigger Modal on Bookmark

Call when user bookmarks an event:

// Inside your bookmark event handler
EventModal.show({
    eventName: event.title,
    imageUrl: event.image,
    buttonLink: event.url
});

3. Features

  • Responsive: Works on mobile, tablet, and desktop
  • Flexible: Accept custom titles, event names, images, and links
  • Accessible: Close with X button or by clicking overlay
  • Animated: Smooth fade in/out with sparkle effects
  • Color Inversion: Purple button inverts to white on hover
